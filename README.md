# Публикация на GitHub Pages

1. Войдите в GitHub и нажмите **New repository**.
2. Укажите имя, например `promo-page`, выберите **Public** и нажмите **Create repository**.
3. Нажмите **Add file → Upload files**.
4. Перетащите в окно *всё содержимое этой папки*: `index.html`, `style.css`, `script.js` и папку `assets`.
5. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**. В **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/(root)`, затем **Save**.
7. Через 1–3 минуты GitHub покажет адрес сайта в этом же разделе. Обычно это `https://ВАШ-ЛОГИН.github.io/promo-page/`.

## Что уже настроено

- Фоновое изображение находится в `assets/background.png`.
- Видео во втором столбце верхнего ряда — `assets/promo.mp4`.
- Щелчок по фону ведёт на заданную ссылку.
- Щелчок по видео не перенаправляет: можно включать, ставить на паузу и менять громкость.

Ссылку можно изменить в `script.js` и в `index.html`.
